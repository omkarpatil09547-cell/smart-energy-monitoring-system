
# ⚡ Smart Energy Monitoring System

## Project Overview
A Python-based dashboard that demonstrates electricity consumption monitoring and estimated energy costs.

## Features
- Voltage display
- Current display
- Power calculation in watts
- Energy consumption in kWh
- Estimated electricity bill calculator
- Weekly energy consumption chart
- High-consumption warning

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly

## How to Run

Install the required libraries:

pip install -r requirements.txt

Start the dashboard:

streamlit run app.py

## Project Status
Software prototype using sample data.
Real-time sensor integration is a future enhancement.
